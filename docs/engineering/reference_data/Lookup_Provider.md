# Lookup Provider

The `LookupProvider` serves as the sole gateway for resolving reference data in the OneApp application layer.

## Responsibilities
- **Resolution:** Resolves `category_code` + `lookup_code` to UUIDs for database insertion.
- **Caching:** Automatically manages cache hits, misses, and invalidations.
- **Validation:** Ensures that a provided `lookup_id` belongs to the expected `category_code`.

## API Interface

```python
class LookupProvider(BaseProvider):
    # Core resolution
    def get_lookup_by_code(self, category_code: str, lookup_code: str, inst_id: int = None) -> LookupDTO: ...
    def get_category_lookups(self, category_code: str, inst_id: int = None) -> List[LookupDTO]: ...
    def resolve_id(self, lookup_id: str) -> LookupDTO: ...
    
    # Validation & Utilities
    def exists(self, category_code: str, lookup_code: str, inst_id: int = None) -> bool: ...
    def validate(self, lookup_id: str, expected_category: str) -> bool: ...
    def get_display_name(self, lookup_id: str) -> str: ...
    def search(self, category_code: str, query: str, inst_id: int = None) -> List[LookupDTO]: ...
    
    # Cache management
    def refresh_cache(self, category_code: str, inst_id: int = None): ...
    def invalidate_cache(self, category_code: str, inst_id: int = None): ...
```
